# Unified Theory: every combo

Generated by `tools/generate-unified-equations.py` from `Claude outputs/unified_theory/equations.json`.

Unified has **5 charges**, each refilling on its own 6 s timer. Every skill can be **cast** or **reserved**. A reserved skill spends a charge and becomes a **trait**; the next cast skill gets every reserved trait, in the order reserved. Up to 4 reserved + 1 cast = a 5-step combo. Order matters (`Prism ▸ Well` ≠ `Well ▸ Prism`). Reserving the same skill twice doubles its trait (capped at × 2). Each link adds +25%; a step taken within 0.4 s of the previous one is an **Insight** (+15%). A combo that uses all three scientists also fires a **Unification**, chosen by the order in which the scientists first appear.
