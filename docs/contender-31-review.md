## Reproduction and live gate

Build the \`native/contender_shadow_lab\` release \`trace\` binary and WASM target.
Copy the WASM output to \`editor/contender.wasm\`, then run
\`rtk proxy node tools/check-contender-31.cjs\`. To verify the actual Lab routes,
start \`rtk proxy node tools/serve-contender-shadow-review.cjs 7311\` with the local
game-reference assets present, then run \`rtk proxy node tools/test-contender-31.cjs\`.
The script can save a review screenshot using \`CONTENDER_LINK_PREVIEW\`.

New definitions use the existing native basic effect with BaseAttack identity
and synchronous HP/shield receipts. Embedded legacy definitions retain the
older attack-callback fallback. Validate item procs and real receipts, dodge
refunds, counter chains, actual glides, the CC handoff and frame time in an
isolated match. The available prior disposable installation uses a different
game build and its profile isolation has not been validated for the current
executable. No live match was verified.

Approve the warning appearance and finish that native acceptance before building
a release package. The draft retains the previous packaged DLL and version
